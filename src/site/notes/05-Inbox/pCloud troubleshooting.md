## Introduction

NASCOMSOFT EMBEDDED LTD uses **pCloud** to provide employees with access to project resources and a designated location for submitting non-code deliverables.

Occasionally, employees may experience difficulties accessing shared folders, locating project files, downloading resources, or uploading completed work.

This guide provides practical steps for resolving common pCloud issues and explains when to contact the Project Manager for assistance.

> [!IMPORTANT] Reporting Problems  
> If a pCloud issue prevents you from working on an assigned task or may affect your deadline, notify the Project Manager promptly.
> 
> Do not wait until the next Monday task review meeting to report a problem that is preventing progress.

---
## 1. Account Registration and Login Problems

### Problem: I cannot create a pCloud account

**Possible causes:**

- Incorrect or incomplete registration information.
- An email address already associated with an existing account.
- Problems completing email verification.

**What to do:**

1. Visit the [pCloud Registration Page](https://e.pcloud.com/#/register?invite=PGwhZlmG5EX).
2. Confirm that you have entered a valid email address.
3. Check your inbox and spam folder for a verification email.
4. If you already have an account, try signing in instead of registering again.
5. Consult the [pCloud Help Center](https://help.pcloud.com/) if the problem persists.

When creating a new account, select the **European data region** to match the company's pCloud account.

### Problem: I cannot log in to my account

**What to do:**

1. Open the [pCloud Web Application](https://my.pcloud.com/).
2. Confirm that you are using the correct registered email address.
3. Check that your password has been entered correctly.
4. Use pCloud's password recovery option if necessary.
5. Consult the official pCloud Help Center if you still cannot sign in.

**Never share your account password with another employee or the Project Manager.**

### Problem: My account is registered in the wrong data region

NASCOMSOFT uses the European pCloud data region.

Accounts registered in a different region may be unable to participate in the company's standard shared-folder invitation workflow.

**What to do:**

1. Check your account settings to confirm your data region.
2. Consult [Managing pCloud Account Settings](https://help.pcloud.com/article/managing-account-settings).
3. Contact the Project Manager before attempting to change accounts or registration details.

## 2. Shared Folder Access Problems

### Problem: I have not received a project folder invitation

**What to do:**

1. Confirm that you have provided the Project Manager with your correct pCloud-registered email address.
2. Check your email inbox and spam folder.
3. Sign in to pCloud and check **Shares → Shared with Me**.
4. If the invitation is still unavailable, contact the Project Manager.

The Project Manager is responsible for granting access to the appropriate project folders.

### Problem: I accepted an invitation but cannot find the folder

**What to do:**

1. Sign in to the correct pCloud account.
2. Open **Shares → Shared with Me**.
3. Look for the project folder.
4. Confirm that you accepted the invitation using the intended account.
5. Contact the Project Manager if the folder is still missing.

### Problem: I can open a folder but cannot upload or modify files

Your access permissions may not allow the action you are attempting.

**What to do:**

1. Confirm that you are working in the correct folder.
2. Check whether you have been instructed to upload files to a separate submissions location.
3. Do not attempt to bypass the folder's access restrictions.
4. Contact the Project Manager if you believe additional access is necessary.
    
> [!info] Access Permissions  
> Access to company project folders is controlled by the Project Manager.
> 
> Being able to view or download a file does not automatically mean you are authorized to modify, move, or delete it.

For additional information, see the [pCloud Folder Invitation Guide](https://help.pcloud.com/article/invite-to-folder).

## 3. Missing or Incorrect Project Resources

### Problem: I cannot find the resources required for my task

**What to do:**

1. Open the [Task Assignment Dashboard](https://nascomsoft.github.io/01-dashboards/tasks-assignment-dashboard/).
2. Confirm the project associated with your task.
3. Open the relevant Project Brief.
4. Follow the project resources link provided in the brief.
5. Check the available folders for the required files.
6. If the resources are still missing, contact the Project Manager.

When reporting the problem, identify the project, the assigned task, and the specific resource you need.

### Problem: I found multiple versions of the same file

**What to do:**

1. Check filenames, version numbers, and available documentation.
2. Review the Project Brief for information about previous contributors.
3. Contact the employee responsible for the relevant work if clarification is needed.
4. Consult the Project Manager if the correct version remains unclear.

Do not assume that the file with the newest-looking name is necessarily the approved version.

### Problem: A project file appears incorrect or outdated

Notify the Project Manager and explain the issue.

Where appropriate, refer to the Project Brief to identify the employee responsible for the file or project component.

Do not overwrite the shared resource without authorization.

## 4. Download Problems

### Problem: A file will not download

**What to do:**

1. Confirm that you have a working internet connection.
2. Refresh the pCloud page and try again.
3. Check that you can still access the shared folder.
4. Try downloading the file again using a supported browser.
5. Check whether your computer has sufficient storage space.
6. If the problem persists, contact the Project Manager.

### Problem: A downloaded file will not open

**Possible causes:**

- The required application is not installed.
- The download was interrupted.
- The file is incomplete or damaged.
- The file format is incompatible with the application being used.

**What to do:**

1. Confirm the file type.
2. Open it using the appropriate application.
3. Download the file again if necessary.
4. Check whether additional related files are required.
5. Contact the Project Manager or relevant project contributor if the problem persists.

For technical project files, make sure you have the necessary software, libraries, and dependencies.

## 5. Upload and Submission Problems

### Problem: I cannot upload my completed work

**What to do:**

1. Confirm that you are using the correct project submissions link from the Project Brief.
2. Check your internet connection.
3. Confirm that the file exists on your computer and is accessible.
4. Try uploading the file again.
5. If the upload fails, check whether the submission location permits the intended upload.
6. Contact the Project Manager if the problem continues.

> [!IMPORTANT] Failed Uploads  
> Do not assume your work has been submitted until you have confirmed that the upload was successful.
> 
> If a technical issue prevents submission before the deadline, notify the Project Manager promptly.

### Problem: I uploaded the wrong file

**What to do:**

1. Identify the incorrect submission.
2. Prepare the correct file.
3. Notify the Project Manager of the mistake.
4. Upload the corrected file as instructed.

Do not delete or overwrite submitted files unless authorized.

### Problem: I need to submit a corrected version

If the Project Manager requests changes:

1. Make the required corrections.
2. Review the updated deliverable.
3. Save it with a clear version number.
4. Upload it to the designated submissions location.
5. Notify the Project Manager that the revised version is available.

Use the recommended naming format: `ProjectName_TaskDescription_EmployeeName_Version`

For example: `SolarProject_TestReport_Mary_v2.pdf`

### Problem: I uploaded my work but it has not been marked as completed

Uploading work is only the submission stage.

The Project Manager must review and verify the deliverables before updating the official task status.

If you have not already done so, notify the Project Manager of your submission.

For more information, read [[03-Vault/Documentation/Project Management/review and verification\|Review and Verification]].

## 6. Source Code and GitHub-Related Issues

Source code is managed through the company's GitHub repositories rather than the standard pCloud submissions process.

If your task involves code:

- Contact the designated GitHub Administrator if you cannot access the required repository.
- Confirm that you have pushed your work to the correct company repository.
- Provide the relevant repository, branch, commit, or pull request reference when notifying the Project Manager.
- Do not substitute a personal GitHub repository for the approved company repository.

For additional information, consult [[Getting Started with GitHub\|Getting Started with GitHub]] and [[03-Vault/Documentation/Project Management/submitting completed work\|Submitting Completed Work]].

## 7. Reporting an Unresolved Problem

If the troubleshooting steps above do not resolve your issue, contact the Project Manager.

To help resolve the problem efficiently, provide the following information:

|Information|What to Include|
|---|---|
|Project|Name of the affected project|
|Assigned task|The task you are attempting to complete|
|Problem|A clear description of what is not working|
|Affected resource|Relevant folder, file, or link|
|Actions attempted|Steps you have already taken|
|Impact|Whether the problem is preventing work or affecting a deadline|

Include a screenshot of an error message where helpful, but avoid exposing passwords, access tokens, or other sensitive information.

### Example Problem Report

**Project:** Autonomous Grass Cutter
**Task:** Circuit Design Review
**Problem:** Unable to access the project resources folder.
**Actions Attempted:** Signed in to pCloud, checked Shared with Me, and reopened the link in the Project Brief.
**Impact:** Cannot download the circuit diagram needed to begin the assigned review.
**Assistance Required:** Confirmation of folder access permissions.

> [!TIP] Report Problems Clearly  
> A specific explanation of the issue helps the Project Manager identify the problem and coordinate a resolution more quickly.

A separate company procedure will address formal task-related complaints and blockers.
