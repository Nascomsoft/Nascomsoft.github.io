## Introduction

At NASCOMSOFT EMBEDDED LTD, project information and resources are organized to help employees easily find what they need to complete their assigned tasks.

The company's online **Knowledge Base and Task Assignment Dashboard** provide information about assigned tasks and projects, while **pCloud** serves as the central storage platform for project files and resources.

This guide explains how to locate your assigned project, access its resources, and download the files needed for your work.

> [!danger] Before You Begin  
> You must have a pCloud account and access to the relevant shared project folder.
> 
> If you have not completed these steps, read [[03-Vault/Documentation/Project Management/getting started with pCloud\|Getting Started with pCloud]] first.

---
## 1. Finding Your Assigned Project

Every employee is expected to check the Task Assignment Dashboard regularly to stay informed about their assigned responsibilities.

### Steps to Find Your Project

1. Visit the [NASCOMSOFT Knowledge Base](https://nascomsoft.github.io/).
2. Open the task assignment dashboard from the sidebar, under dashboards or go there instantly using this [link](https://nascomsoft.github.io/01-dashboards/tasks-assignment-dashboard/
3. Locate your name under the relevant task status or weekly assignment.
4. Open your task assignment note to view the tasks assigned to you.
5. Identify the project associated with the task you intend to work on.
6. Open the relevant **Project Brief** to understand the project's objectives, requirements, and other important information.

> [!IMPORTANT] Multiple Tasks and Projects  
> A project may have multiple tasks assigned to different employees at the same time.
> 
> Similarly, an employee may be assigned tasks across different projects.
> 
> Always confirm the project and task you are working on before accessing or submitting files.

---
## 2. Accessing Project Files on pCloud

Each project has a dedicated folder on pCloud containing the files and resources relevant to its execution.

The Project Brief serves as the entry point for locating these resources.

### Steps to Access Project Resources

1. Open the Project Brief associated with your assigned task.
2. Locate the **pCloud project folder link** provided in the brief.
3. Click the link to open the project folder in pCloud.
4. Sign in to your pCloud account if prompted.
5. Navigate through the shared folder to locate the resources relevant to your task.

Depending on the project, these resources may include:
- Project specifications and reference documents
- Research materials and technical documentation
- Circuit diagrams, schematics, and design files
- Source code and software resources
- Hardware specifications and component datasheets
- Testing resources and other supporting files
    
**Note:** You may only be able to access folders and files for which you have been granted permission by the Project Manager.

If you cannot access a required folder or resource, contact the Project Manager.

---
## 3. Downloading Project Resources

Employees are expected to **download the resources they need and work on them locally** using the appropriate software and tools.

You do not need to install the pCloud desktop application or synchronize shared folders to your computer.

### Steps to Download Files

1. Open the relevant shared project folder in pCloud.
2. Locate the file or folder you need.
3. Select the file and choose the **Download** option.
4. Save the downloaded file to an appropriate location on your computer.
5. Open the file using the relevant application.

If your task requires multiple related files, download all necessary resources while preserving their folder organization.

For example, a software development task may require source code, configuration files, libraries, and supporting documentation.

> [!TIP] Keep Your Files Organized  
> Create a dedicated working folder on your computer for each project.
> 
> This will help you organize downloaded resources, working files, and completed deliverables without mixing files from different projects.

---
## 4. Handling Project Resources

Project resources may be shared among multiple employees working on different aspects of the same project.

To maintain consistency and avoid unnecessary errors:
- Download only the resources relevant to your assigned responsibilities.
- Preserve original reference files and maintain their folder structure where necessary.
- Avoid modifying or deleting existing files in shared project folders without authorization.
- Keep your local working files organized and clearly named.
- Confirm with the Project Manager when you are unsure which file or version to use.
- Do not share project resources with unauthorized individuals.

> [!IMPORTANT] Working with Shared Resources  
> Changes made to downloaded files on your computer do not automatically update the files stored in pCloud.
> 
> Completed work must be uploaded separately to the designated submissions folder for review.

## 5. Frequently Asked Questions

**Where can I find information about my assigned project?**

Visit the Task Assignment Dashboard, open your weekly assignment note, and follow the relevant project brief.

**What if I cannot access the project folder?**

Confirm that you are signed in to the correct pCloud account and have accepted the folder invitation. If access is still unavailable, contact the Project Manager.

**What if a required file is missing?**

Review the available project resources and confirm that you are checking the correct folder. If the file is still missing, notify the Project Manager.

**Can I modify files directly in the shared project folder?**

Only when explicitly authorized. The standard workflow is to download the required resources, work locally, and submit completed deliverables for review.

**Do I need to synchronize the project folder with my computer?**

No. Employees are expected to download the files they need and upload their completed work through the pCloud web application.

**What if I need additional resources that are not available?**

Contact the Project Manager and explain which resources are required and why they are needed for your assigned task.
