## 1. Project & Task Management Workflow

To improve project coordination, file accessibility, and documentation, NASCOMSOFT uses an online **Project and Task Management Dashboard** alongside **pCloud** for project file storage and collaboration.

Employees can view their assigned tasks, access project information, download required resources, and submit completed work for review.

_The workflow is simple:_

**View Assignment → Access Project Folder → Download Resources → Work Locally → Upload Deliverables → Project Manager Reviews**
