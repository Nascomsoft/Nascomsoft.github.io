## 1. Introduction

To improve project coordination, file accessibility, and documentation, NASCOMSOFT uses **pCloud** as a central platform for storing and sharing project resources.

This system allows employees to access the files needed for their assigned tasks, work independently, and submit completed deliverables for review.

pCloud works alongside the company's online [knowledge base](https://nascomsoft.github.io/) **/** [project and task management website](https://nascomsoft.github.io/01-dashboards/tasks-assignment-dashboard/), where employees can view their weekly assignments and access project briefs.

_The workflow is simple:_

**View Assignment → Access Project Folder → Download Resources → Work Locally → Upload Deliverables → Project Manager Reviews**

## 2. Getting Started with pCloud

Every employee who requires access to project resources must have a pCloud account.

### 2.1 Creating a pCloud Account

If you do not already have an account:

1. Visit [pCloud](https://e.pcloud.com/#/register?invite=PGwhZlmG5EX)
2. Select the option to create a free account.
3. Enter your email address and complete the registration process.
4. Select the appropriate data region -  **european region**
5. Verify your email address using the verification message sent by pCloud.
6. Sign in to your account at [my.pCloud](https://my.pcloud.com/).
7. Provide your registered email address to the Project Manager so you can be invited to the appropriate project folders.

**Important:** Use an email address you can access regularly. You must register in the same pCloud data region as the company's account to use the standard folder invitation feature.

For additional help, visit the [pCloud Help Center](https://help.pcloud.com/) or read the [Account Settings Guide](https://help.pcloud.com/article/managing-account-settings).

### 2.2 Accessing Shared Project Folders

Access to project folders is managed by the Project Manager.

Once you have been assigned to a project:

1. The Project Manager will invite your registered pCloud email address to the relevant folder.
2. Check your email for the folder invitation.
3. Open the invitation and sign in to pCloud.
4. Accept the invitation.
5. Go to **Shares → Shared with Me** in pCloud.
6. Locate the shared project folder.

You will only be able to perform actions permitted by the access rights assigned to your account.

For further information, see [pCloud — Invite to Folder](https://help.pcloud.com/article/invite-to-folder).


### 2.3. File Access and Responsibilities

The Project Manager controls access to shared project folders.

Permissions may vary depending on the employee's responsibilities and the nature of the project.

Employees are expected to:

- Use only the folders and resources they have been authorized to access.
- Avoid modifying or deleting existing project resources without authorization.
- Keep their pCloud account credentials private.
- Avoid sharing project files or access links with unauthorized individuals.
- Report missing files or access difficulties to the Project Manager.

The Project Manager is responsible for granting appropriate access, reviewing submissions, and organizing approved project deliverables.


## 3. Accessing Project Resources

Each project has a dedicated folder containing the resources required for its execution.

These may include:
- Project specifications and reference documents
- Research materials and technical documentation
- Circuit diagrams, schematics, and design files
- Source code and software resources
- Hardware specifications and datasheets
- Other relevant project files

### 3.1 Finding Your Project

1. Visit the company's published Task Assignment Dashboard.
2. Open your weekly task assignment note.
3. Identify the project associated with your task.
4. Open the relevant project brief to understand the project requirements.
5. Follow the pCloud link provided in the project brief.
6. Sign in to your pCloud account if required.
7. Navigate to the files relevant to your assignment.

**Note:** A project may have multiple employees working on different tasks. Each employee is responsible for accessing and using the resources relevant to their assigned work.

### 3.2 Downloading Files

Employees are expected to download the resources they need and work on them locally.

To download a file:
1. Open the appropriate shared project folder in pCloud.
2. Locate the required file or folder.
3. Select the download option.
4. Save the file to your computer.
5. Open it using the appropriate application.

For projects containing multiple related files, download the necessary files together while preserving their organization.

You do not need to install the pCloud desktop application or synchronize project folders to your computer.

## 4. Working on Assigned Tasks

After downloading the required resources, proceed with your assigned work using the appropriate tools.

Depending on the project, this may involve programming, circuit design, research, technical writing, hardware development, testing, or other activities.

While working:

1. Follow the requirements specified in your task assignment.
2. Keep your working files organized.
3. Preserve original reference materials.
4. Coordinate with the Project Manager when additional resources or clarification are required.
5. Prepare all deliverables requested in your assignment.

Where multiple employees contribute to the same project, each person should focus on their assigned responsibilities and coordinate where tasks depend on one another.

## 5. Submitting Completed Work

Every project will have a **dedicated submissions folder** for receiving completed work.
This dedicated folder link will be made available on the project brief

Employees must upload their completed deliverables to this folder for verification by the Project Manager.

### 5.1 Uploading Deliverables

Once you have completed your assigned task:

1. Sign in to [my.pCloud](https://my.pcloud.com/).
2. Open the shared project folder.
3. Navigate to the designated **Submissions** folder.
4. Select the upload option.
5. Choose the completed files from your computer.
6. Wait for the upload to finish.
7. Confirm that the correct files have been uploaded successfully.
8. Notify the Project Manager that your work is ready for review.

Submit all files necessary to evaluate the completed task, as specified in your assignment.

### 5.2 File Naming

Use descriptive filenames that make submitted work easy to identify.

A recommended naming format is:

`ProjectName_TaskDescription_EmployeeName_Version`

**Examples:**

- `GrassCutter_MotorControl_John_v1.zip`
- `IoTSystem_CircuitDiagram_Mary_v1.pdf`
- `SolarProject_ResearchReport_David_v1.docx`

Where a task produces several related files, organize them in a clearly named folder before submission.

Avoid generic filenames such as `final.docx`, `newcode.zip`, or `project1.pdf`.

### 5.3 Submission Rules

- Upload completed work only to the designated submissions location.
- Do not move submitted files into permanent project folders yourself unless instructed.
- Do not delete or replace another employee's submissions.
- Ensure uploaded files are complete, readable, and properly named.
- Where corrections are requested, submit a revised version that can be distinguished from the previous submission.

**Important:** Uploading files does not automatically mean a task has been approved or marked as completed.

## 6. Review and Verification

All submitted work is subject to review by the Project Manager.

The review process is as follows:

1. The employee uploads the required deliverables.
2. The employee notifies the Project Manager.
3. The Project Manager reviews the submitted work against the assigned requirements.
4. If corrections are necessary, the employee is informed and expected to revise the work.
5. Once the work is accepted, the Project Manager moves the approved files to their appropriate permanent location within the project folder.
6. The Project Manager updates the task completion status.

Employees should retain their local working copies until the submitted work has been accepted.

### Project Completion

A project is not considered officially closed until its required documentation has been completed and verified.

Documentation activities may be assigned as separate tasks, depending on the project's requirements.


## 7. Troubleshooting

**I cannot access a project folder.**

Confirm that you are signed in with the correct pCloud account and have accepted the folder invitation. If the folder is still unavailable, contact the Project Manager.

**I cannot upload files to the submissions folder.**

Check that you are using the correct folder and that your internet connection is working. If the upload option is unavailable or access is denied, contact the Project Manager.

**I cannot find a required project resource.**

Review the project brief and available project folders. If the resource is missing, notify the Project Manager rather than proceeding with incomplete information.

**I uploaded the wrong file.**

Notify the Project Manager and provide the correct file. Do not delete or overwrite files unless authorized.

**My submission requires corrections.**

Make the requested changes locally and upload a clearly identified revised version for another review.
