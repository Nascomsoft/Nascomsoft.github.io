## Introduction

NASCOMSOFT EMBEDDED LTD uses **pCloud** as a central platform for storing, accessing, and sharing project files and resources.

As an employee, you will use pCloud to access resources needed for your assigned tasks and submit completed work for review.

Before you can access project files, you must create a pCloud account and be granted access to the relevant project folders by the Project Manager.

This guide explains how to get started.

---

## 1. Creating a pCloud Account

Every employee who requires access to project resources must have a pCloud account.

If you already have a pCloud account, proceed to **Section 2**.

### Steps to Create an Account

1. Visit the [pCloud Registration Page](https://e.pcloud.com/#/register?invite=PGwhZlmG5EX).
2. Select the option to create a free account.
3. Enter your email address, create a secure password, and complete the registration process.
	![pcloud login page.png\|606](/img/user/03-Vault/Images/Documentation/pcloud%20login%20page.png)

4. When asked to select a data region, choose **Europe (European Union)**.
	![pcloud - select region.jpeg\|617](/img/user/03-Vault/Images/Documentation/pcloud%20-%20select%20region.jpeg)
5. Verify your email address using the verification email sent by pCloud.!
6. Once registration is complete, sign in to your account through the [pCloud Web Application](https://my.pcloud.com/).
7. Provide your registered email address to the Project Manager so you can be granted access to the appropriate project folders.

> [!IMPORTANT] Data Region  
> Make sure you select the **European data region** when creating your account.
> 
> pCloud requires accounts to be in the same data region for its standard shared-folder invitation feature. Selecting a different region may prevent you from accessing the company's shared project folders.

You can access pCloud directly through your web browser. Installing the desktop application is not required for the company's project workflow.

---

## 2. Accessing Shared Project Folders

Project files are organized into dedicated folders on pCloud.

The Project Manager controls which employees can access each folder, depending on their assigned tasks and responsibilities.

### How to Accept a Folder Invitation

Once you have been assigned to a project:
1. The Project Manager will send a folder invitation to your registered pCloud email address.
2. Check your email for the invitation.
3. Open the invitation and sign in to your pCloud account if prompted.
4. Accept the invitation to access the shared folder.
5. In the pCloud web application, navigate to **Shares → Shared with Me**.
6. Locate and open the project folder shared with you.

You can now access the project resources permitted by your assigned access rights.

> [!tip] Folder Access  
> Not every employee will have access to every project folder.
> 
> Access is granted according to project assignments and responsibilities. If you cannot find a folder you need, contact the Project Manager.

For more information, read the official guide by pCloud on [Invite to Folder](https://help.pcloud.com/article/invite-to-folder).

---

## 3. File Access and Responsibilities

Access to project resources is managed by the Project Manager.

Depending on your responsibilities, you may be granted permission to view, download, upload, or modify files within specific folders.

All employees are expected to follow these guidelines:

- **Access only authorized resources:** Use project folders and files relevant to your assigned responsibilities.
- **Preserve original files:** Do not modify, rename, move, or delete existing project resources without authorization.
- **Protect your account:** Keep your pCloud login credentials private and do not share your account with others.
- **Respect project confidentiality:** Do not share project files or folder access links with unauthorized individuals.
- **Report access problems:** If you cannot access a required folder or file, notify the Project Manager.

> [!IMPORTANT] Remember  
> Having access to a project folder does not automatically mean you are authorized to modify or delete its contents.
> 
> Please follow the guidelines and instructions put in place to make collaboration easy and stress free for everyone

## 4. Frequently Asked Questions

**Do I need to pay for a pCloud account?**

No. Employees can create a free pCloud account to participate in the company's shared-folder workflow.

**Do I need to install pCloud on my computer?**

No. You can access shared project files, download resources, and upload completed work directly through your web browser.

**What if I already have a pCloud account?**

You can use your existing account if it is registered in the European data region. Otherwise, contact the Project Manager before proceeding.

**What if I do not receive a folder invitation?**

Check your email inbox and spam folder. Confirm that you provided the correct registered email address to the Project Manager. If the invitation is still missing, contact the Project Manager.

**What if I cannot find a project folder?**

Make sure you have accepted the folder invitation and are signed in to the correct account. If the folder is still unavailable, contact the Project Manager.

**Can I share a project folder with another employee?**

Do not share project folders or files with others without authorization. The Project Manager is responsible for managing access.
